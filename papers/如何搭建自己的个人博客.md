# 如何搭建自己的个人博客

考虑到搭建服务器、IP、域名或是其他服务都要花费不小的成本，但我们有一种**零成本方案**。

对于静态网页（内容固定、直接存储在服务器上的网页），有非常多成熟的方案。

看到这里：[此项目 Github 仓库地址](https://github.com/wiphi233/wiphi233.github.io)

用 Github 托管源码，Github Pages 能很方便地部署静态网页，缺点：网址必须是 `<你的用户名>.github.io`，且访问较慢，但可以尝试 [fast-github](https://github.com/creazyboyone/FastGithub)

另外有个低成本部署方案，只需要买域名：

[Cloudflare Pages](https://www.cloudflare-cn.com/developer-platform/products/pages/)
